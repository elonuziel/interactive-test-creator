Builder → Quiz browser smoke test

This checklist intentionally uses no external browser automation dependency. Run it from the local HTTP server and record any failing checkpoint in the issue/PR.

  1. Open the builder. Confirm the page loads without a console error.
  2. Import a valid questions JSON file. Confirm question cards appear in the preview.
  3. Edit question text and an option. Confirm the edited values remain visible after another edit.
  4. Click הורד מבחן עצמאי. Confirm an HTML file downloads successfully.
  5. Open the downloaded HTML file. Confirm it loads questions without a questions.json request.
  6. Start the quiz, answer one question, navigate, and return. Confirm the answer remains selected.
  7. Refresh the standalone quiz before completing it. Confirm the resume notice appears.
  8. Open browser developer tools and confirm there are no errors during the flow.
